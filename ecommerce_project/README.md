# متجر إلكتروني متكامل

## المتطلبات
- Node.js
- MongoDB

## خطوات التشغيل

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## إعداد البيئة
```
PORT=5000
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
STRIPE_SECRET_KEY=your_stripe_key
```
